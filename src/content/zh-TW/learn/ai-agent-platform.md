# 為生產而生的 AI 代理平台

多數團隊從框架開始。他們串起 LangGraph 節點或 CrewAI crews,做出能跑的 Demo,然後撞牆:誰管容器?API 金鑰放哪?要怎麼阻止流氓代理在一夜之間燒掉 $500 token?

**AI 代理平台** 在你寫下第一個代理前就回答這些問題。OpenLegion 是一個代管的 AI 代理平台,內建沙箱任務執行、金庫保管的憑證、每代理點數預算與目標與任務協調(目標 → 任務 → 代理)— 全部預設啟用。它是代管網頁應用:以 Google 登入即可開始,沒有任何東西需要安裝。

<!-- SCHEMA: DefinitionBlock -->

> **什麼是 AI 代理平台?**
> AI 代理平台是用於在生產環境部署、編排與治理自主 AI 代理的代管基礎設施。與原始框架不同,平台處理隔離、憑證管理、成本控制與可觀測性,讓團隊無需從零打造 DevOps 就能交付代理。

## 重點摘要

- **平台,不是框架** — OpenLegion 管理執行、憑證、預算與核可。你管理代理邏輯。
- **金庫保管的憑證** — 憑證在模型之外注入,模型只持有一個代號。代理永不見原始金鑰。
- **每項任務一次沙箱執行** — 每項任務按需執行後即停止,因此沒有長期存在的代理程序可供入侵,而代理所寫的程式碼預設沒有網路存取。
- **每代理預算強制執行** — 每個代理都有自己的點數預算,每點 $0.001,具自動硬性截止。沒有意外帳單。
- **模型預設** — 可按代理或按工作區選擇 Smartest、Smart 或 Normal。你永遠不必接供應商或輪替金鑰。
- **可稽核的目標與任務協調** — 工作以目標 → 任務 → 代理組織,由助理建立所需的隊友。沒有「CEO 代理」做不透明決策。
- **內建工具組** — 網頁搜尋與擷取、檔案、長期記憶、排程、沙箱程式碼執行,以及可分享的交付成果。每個代理都能使用。
- **持久化代理記憶** — 代理跨會話記憶,具向量搜尋、工作區檔案與錯誤學習。脈絡自動管理。

## 代管 vs 自我託管:何時各自合適

AI 代理框架與 AI 代理平台的區別在部署時最重要。框架給你基礎元件 — 代理定義、工具整合、對話模式。平台給你生產層:代理在哪裡執行、如何存取憑證、什麼能阻止它們失控。

**自我託管框架**(LangGraph、CrewAI、AutoGen)給你最大控制。你擁有基礎設施。你配置容器。你打造憑證管線。這在你的團隊有專責 DevOps 量能,以及代理需要深度整合既有基礎設施時可行。

**代管 AI 代理平台** 處理營運層,讓團隊聚焦於代理邏輯。OpenLegion 就在這 — 但有一個關鍵差異:其底層引擎以 PolyForm Perimeter License 1.0.1 原始碼可取得發布。你獲得平台級營運(執行隔離、金庫、預算控制),底下卻不是一個黑盒。

問題不在於哪個「比較好」,而在於團隊應該把工程小時花在代理安全基礎設施,還是代理本身。

### 何時自我託管合適

- 你有嚴格的資料居住地需求,排除任何代管服務
- 你的代理需要與既有 on-prem 基礎設施深度整合
- 你的團隊已運作 Kubernetes 叢集,具成熟 DevOps 實務
- 你需要在代管平台未公開的層級客製化執行環境

### 何時代管 AI 代理平台合適

- 你需要在數天內、而非數月,讓代理進生產
- 你的團隊 1-5 人,無法投入專責基礎設施人力
- 你需要 [AI 代理安全](/learn/ai-agent-security) 保證,但不想自己打造
- 你想要成本控制與請求追蹤,且不必手動檢測一切

## 模型預設系統 — 為何重要

多數代管 AI 平台把模型選擇丟給你:挑供應商、接金鑰、輪替金鑰、供應商改版時重新調校。這造成兩個問題:成本不透明與供應商鎖定。

OpenLegion 採不同做法。模型以預設組合挑選 — Smartest、Smart 或 Normal — 可按代理或按工作區設定,因此沒有供應商要接、也沒有金鑰要輪替。工作以點數計量、每點 $0.001,而每項任務的精確成本都在應用程式中看得見。

這在三方面很重要:

**成本透明。** 你能精確看到每個代理花了多少、每項任務花了多少。每個工作單位都是一次已記錄、有標價的喚醒,而不是月結帳單上的一行。

**模型彈性。** 每代理可換預設。複雜推理跑 Smartest、日常工作跑 Smart、大量分類跑 Normal — 全部在同一工作區中,從同一儀表板管理。

**無鎖定。** 若你離開 OpenLegion,你可以匯出整個工作區 — 代理、任務、收據與交付成果 — 並抹除留下的資料。沒有需要遷移的專有模型層。

## 適合誰

你正在交付代理驅動產品,並需要從第一天就安全。OpenLegion 給你生產基礎設施 — 沙箱執行、憑證金庫、成本控制 — 無需聘請 DevOps 團隊。描述你想要的成果,助理就會建立達成它所需的隊友。

### 快速交付的新創團隊

你的團隊 2-10 位工程師。你需要這個 sprint、而非下一季,讓代理進生產。沒有安裝步驟:OpenLegion 是代管網頁應用,以 Google 登入即可。Free 是 $0、含 1,000 點一次性點數且無需信用卡,因此註冊後幾分鐘內第一個代理就會開始工作。

### 企業安全團隊

你需要請求追蹤與工作流程可觀測性、能在代理被入侵後仍存活的憑證隔離,以及防止成本失控的預算控制。OpenLegion 的架構為要求縱深防禦的環境而設計。可稽核的目標與任務協調意味著每個工作流程步驟都明確且可追蹤 — 控制平面沒有不透明的 LLM 決策。完整威脅模型請參閱我們的 [AI 代理安全](/learn/ai-agent-security) 頁面。

## 內建工具可擴展性

OpenLegion 把工具隨平台一起出貨,而不是要你自己接伺服器。每個代理從建立那一刻起就具備網頁搜尋與擷取、檔案處理、長期記憶、排程、沙箱程式碼執行與可分享的交付成果。推出時的連接器為 Google 日曆與你挑選的 Google 雲端硬碟檔案;推出時不支援 Model Context Protocol (MCP)。

內建工具意味著代理在你建立它的那一刻就能派上用場,沒有東西要安裝、也沒有東西要設定。每次工具呼叫都是意圖,在發生前由單一政策引擎檢查,因此代理維持在權限邊界內,而每次呼叫都會記錄成收據。

## 持久化代理記憶

OpenLegion 中的代理使用向量搜尋、工作區檔案與錯誤學習,跨會話維持記憶。當代理遇到問題並解決時,解法會被儲存並於未來會話中召回 — 降低重複失敗並隨時間提升執行品質。

記憶以代理為範圍,並與其他每個代理、其他每個工作區隔離。自動脈絡管理藉由僅呈現與當前任務相關的記憶來維持 token 用量效率,而非載入整個對話歷史。

## 架構:每個動作前的單一政策引擎

OpenLegion 將每個工作區分為四個信任邊界,加上一個擁有者決策層:

**不可信外部輸入。** 任何來自使用者或第三方的輸入:網頁聊天、Telegram、Slack、接收電子郵件與 webhook 端點。所有輸入在抵達政策引擎前皆經過提示注入防護驗證與清理。

**代理的執行(不可信)。** 每項任務按需執行後即停止,代理所寫的程式碼在預設無網路存取的沙箱中執行。即便某次執行完全被入侵,也無法存取你的憑證、其他代理的資料或另一個工作區。

**政策引擎(可信)。** 單一層會在每個動作發生前把它當作意圖檢查,並記錄成擁有者可讀的收據:工具呼叫、委派、核可、成本。它持有共享的目標與任務紀錄、憑證金庫、權限矩陣,以及每個代理的點數預算。這是大腦 — 也是唯一接觸你憑證的元件。

**擁有者或管理員決策。** 工作只在三道關卡停下來等待核可:代表你接觸第三方、刪除資料,以及對不受信任的內容採取行動。這個決定由擁有者或管理員在應用程式中做出,永遠不由代理做出。

**僅限內部的控制平面。** 最受限階層:建立代理、授予工具權限與變更方案等管理操作,透過單一且限定於單一工作區的管理 API 進行。

這個架構意味著 [AI 代理編排](/learn/ai-agent-orchestration) 與安全不是分開的關切 — 它們是同一個系統。

## 常見問題

### 什麼是 AI 代理平台?

AI 代理平台是處理執行自主 AI 代理營運關切的代管基礎設施:沙箱執行隔離、憑證管理、成本控制、編排與可觀測性。它位於 LangGraph 或 CrewAI 等框架之上,提供框架留給你處理的生產層。

### 生產環境最佳 AI 代理平台是什麼?

生產環境最佳 AI 代理平台取決於你的安全與營運需求。若你需要內建的執行隔離、金庫保管的憑證,以及每代理預算控制,且不想打造自訂基礎設施,OpenLegion 即裝即用提供這些。對於深度投入微軟生態圈的團隊,Azure AI Agent Service 值得評估。若想要最大彈性、願意投入更多 DIY,自我託管 LangGraph 搭配 LangSmith 提供強大可觀測性。

### 什麼是企業 AI 代理平台?

企業 AI 代理平台在基本代理編排之上加上治理、合規與安全控制。關鍵需求包括:憑證隔離(代理永不見原始 API 金鑰)、工作流程可追蹤性、防止成本失控的預算強制執行、角色式存取控制,以及支援資料居住地需求的部署選項。OpenLegion 的架構為要求這些控制的環境而設計。

### 我能用自己的 API 金鑰託管 AI 代理嗎?

不需要,而且你也不必。模型存取已經內含:為代理或工作區挑一個預設 — Smartest、Smart 或 Normal — 由 OpenLegion 處理供應商。工作以點數計量、每點 $0.001,因此你能看到每項任務的精確成本。Free 是 $0,含 1,000 點一次性點數且無需信用卡。

### 代管 vs 自我託管 AI 代理:差別是什麼?

代管 AI 代理平台為你處理容器佈建、憑證金庫、成本控制與可觀測性。自我託管意味著你在自有基礎設施上部署框架(LangGraph、CrewAI、AutoGen),並自行打造這些營運層。代管較快達到生產,且需較少 DevOps 投資。自我託管給予最大基礎設施控制。OpenLegion 是代管的:以 Google 登入即可開始,而底層引擎以 PolyForm Perimeter License 1.0.1 原始碼可取得發布。

### OpenLegion 與其他 AI 代理平台相比如何?

OpenLegion 以安全優先架構區隔。根據撰寫當下的公開文件,沒有其他主要 [AI 代理框架](/learn/ai-agent-frameworks) 提供內建的金庫保管憑證、每項任務一次沙箱執行,或原生每代理預算強制執行。跨 OpenClaw、LangGraph、CrewAI、AutoGen 與 Semantic Kernel 的詳細比較,請參閱我們的 [框架比較](/learn/ai-agent-frameworks)。

### OpenLegion 使用什麼授權?

OpenLegion 引擎採 PolyForm Perimeter License 1.0.1 原始碼可取得授權,並可在 [GitHub](https://github.com/openlegion-ai/openlegion) 取得。代管平台為專有,也是團隊在不自行管理任何基礎設施的情況下執行代理的地方。

### 我能多快部署第一個代理?

幾分鐘,而且沒有任何東西需要安裝。以 Google 登入,告訴助理你想完成什麼,它就會建立所需的代理。Free 是 $0、含 1,000 點一次性點數且無需信用卡,因此從登入到第一項任務之間沒有任何阻礙。
