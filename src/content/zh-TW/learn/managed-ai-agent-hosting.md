# 為安全代理艦隊而生的代管 AI 代理託管

你想要的是一支 AI 勞動力。你得到的卻是一份 DevOps 的兼差。代管 AI 代理託管把這份差事還給你。它運行你的代理所需的伺服器、隔離、憑證金庫與預算,讓你完全無需自行佈建。OpenLegion 是代管網頁應用:以 Google 登入即可開始,沒有任何東西需要安裝、也不必租用專屬 VPS,你的金鑰保存在代理永不觸碰的金庫中,並預設為每個代理設定預算。你帶來一個目標;底下的地基由我們來運行。

<!-- SCHEMA: DefinitionBlock -->

> **什麼是代管 AI 代理託管?**
> 代管 AI 代理託管是一種服務,負責佈建、隔離、保護並營運自主 AI 代理所運行的基礎設施:容器、憑證儲存、預算、網路,以及控制儀表板,讓團隊無需自行打造或維護該基礎設施,就能部署代理艦隊。

## 重點摘要

- 代管 AI 代理託管移除了你與一支運行中團隊之間的工作:無需設定伺服器、無需調校 Docker、無需營運金庫。
- 代理是持久紀錄而非伺服器:建立一個是即時的,閒置的代理不花錢,一個工作區可以運行數百個。
- 憑證存放在金庫中,並在模型之外注入,模型只持有一個代號,因此被入侵的代理無法讀取它們。
- 每個代理都有自己的預算,而每個工作單位都是一次以點數計量、每點 $0.001 的已記錄喚醒。
- 引擎在 PolyForm Perimeter License 1.0.1 下原始碼可取得發布;代管平台則為專有。
- Free 是 $0、含 1,000 點一次性點數且無需信用卡;Pro 是 $29/月、含 10,000 點;Team 是 $99/月、含 35,000 點。

## 「只是跑個代理」的隱藏成本

架起一個代理是一個週末的事。運行一支你能信任的艦隊則是一季的事。

在原型與生產之間的某處,工作悄悄改變了形貌。你不再調校提示,而開始調校容器。你不再思考代理該說什麼,而開始思考它的 API 金鑰存放在哪、當其中一個在凌晨三點陷入迴圈時會發生什麼,以及如何阻止一個被入侵的代理觸及其餘九個。這些都不是你原本打算做的工作。但它們全都是決定這些代理能否安心放著運行的工作。

代管託管的存在,正是為了吸收這一層。透過 OpenLegion 的託管方案,你可獲得:

- **代管網頁應用**,沒有任何東西需要安裝、也不必租用專屬 VPS — 以 Google 登入即可開始。
- **每項任務一次沙箱執行**,每項任務按需執行後即停止,而代理所寫的程式碼預設沒有網路存取。
- **憑證金庫**,將 API 金鑰與 OAuth token 完全保存在模型之外,模型只持有一個代號。
- **每代理預算強制執行**,具硬性截止,因此陷入迴圈的代理無法產生意外帳單。
- **控制儀表板**,用以部署範本、與代理對話、即時觀看成本與健康狀態,並暫停任何行為失常之物。
- **每個方案皆含點數**,每月重置,而模型以預設組合挑選 — Smartest、Smart 或 Normal。

## 代管託管 vs 自我託管:如何選擇

OpenLegion 的平台僅有代管版本,底層引擎則以原始碼可取得方式發布。以下比較的是自行運行代理基礎設施與交由他人運行之間的一般取捨。

| 考量 | 自我託管(PolyForm Perimeter License 1.0.1) | 代管託管 |
|---|---|---|
| 誰運行伺服器 | 你 | OpenLegion |
| 設定時間 | 在你的機器上三道指令 | 以 Google 登入,無需安裝 |
| 憑證金庫 | 由你營運 | 為你營運,且在模型之外 |
| 更新與修補 | 你拉取並重新部署 | 為你套用 |
| 資料居住地 | 完全在你的基礎設施上 | 在我們運行的代管平台上 |
| 最適合 | 受監管、氣隙隔離、完全掌控 | 想要今天就有團隊運行的團隊 |
| 成本模式 | 你自己的伺服器成本 | Free $0、Pro $29/月、Team $99/月 |

當合規、資料居住地或對主機的完全掌控,勝過運行它的成本時,選擇自我託管。當你希望代理今天下午就開始工作,且寧可不去擁有一個金庫、一個執行環境與一套更新節奏時,選擇代管託管。OpenLegion 在推出時僅提供代管平台,因此沒有自我託管平台可以轉移過去。

## 當你按下部署時會發生什麼

以 Google 登入,你的工作區就準備好了 — 沒有任何東西需要佈建。系統會同時建立一個助理,由它建立所需的隊友。接著你描述想要的團隊:一個研究小組、一條銷售管線、一間內容工作室,平台便把每個角色建立成一筆持久紀錄,各具自己的記憶、預算與工具權限。

這些代理透過 [編排層](/learn/ai-agent-orchestration) 協調:工作以目標 → 任務 → 代理組織,並具事件喚醒與隊友之間的委派。每個動作都是意圖,在發生前由單一政策引擎檢查,這讓行為可稽核、成本可預測。你可在每個方案的網頁聊天中與代理對話,Pro 起可透過 Telegram 與 webhook,Team 以上可透過 Slack 與接收電子郵件。

## 你不必自行打造的安全

安全託管代理最困難的部分,正是團隊最常略過的部分,因為它在失效之前都是隱形的。OpenLegion 的代管平面強制執行 [AI 代理安全](/learn/ai-agent-security) 模型中所述的同一套縱深防禦,且預設啟用:

- 每項任務一次沙箱執行,沒有長期存在的代理程序可供入侵。
- 憑證金庫在模型之外注入憑證,因此代理永不握有原始金鑰。
- 每代理權限矩陣,規範每個代理可使用哪些工具、檔案與操作。
- 在每個邊界進行輸入清理、SSRF 防護與提示注入強化。
- 每代理預算上限,並以「失效即關閉」方式運作。

你藉由註冊就繼承了這些,而不必閱讀一份強化指南並自行實作。關於底層的執行環境,請參閱 [AI 代理平台](/learn/ai-agent-platform) 概覽。

## 常見問題

### 什麼是代管 AI 代理託管?

代管 AI 代理託管是一種服務,負責佈建並營運自主 AI 代理所需的基礎設施:隔離容器、憑證金庫、預算強制執行、網路,以及控制儀表板,讓團隊無需打造或維護該基礎設施,就能部署並運行代理艦隊。在 OpenLegion,你以 Google 登入即可開始 — 沒有任何東西需要安裝,也不必租用專屬 VPS。

### 代管託管與自我託管 OpenLegion 有何不同?

OpenLegion 是代管網頁應用,推出時沒有自我託管平台。一般而言,自我託管意味著你自行運行伺服器、營運金庫並套用更新,適合受監管或氣隙隔離的環境。代管託管意味著 OpenLegion 運行平台、營運金庫並為你修補。底層引擎以 PolyForm Perimeter License 1.0.1 原始碼可取得發布;代管平台則為專有。

### 託管握有我 API 與錢包金鑰的 AI 代理安全嗎?

安全,只要金鑰從不存在於代理內部。在 OpenLegion 上,API 金鑰與 OAuth token 都保存在金庫中,並在模型之外注入,模型只持有一個代號,因此即便代理完全被入侵,也無法讀取或外洩該機密。OpenLegion 完全不持有錢包金鑰或代理資金。

### 代管 AI 代理託管要多少成本?

Free 是 $0、含 1,000 點一次性點數且無需信用卡;Pro 是 $29/月、含 10,000 點;Team 是 $99/月、含 35,000 點;Enterprise 自 $1,500 起。費用涵蓋代管平台、憑證金庫、儀表板,以及方案內含的點數 — 沒有專屬 VPS 需要付費。工作以點數計量、每點 $0.001,方案內含點數每月重置,你購買的點數包則永不過期。

### 使用代管託管需要懂 Docker 或 DevOps 嗎?

不需要。OpenLegion 是代管網頁應用:以 Google 登入即可開始 — 沒有任何東西需要安裝。你透過儀表板作業:描述你想要的團隊,助理便會建立所需的隊友。Docker、Python 與伺服器管理完全不在其中。

### 我日後能從代管託管轉移到自我託管嗎?

推出時不行。代管平台是目前運行 OpenLegion 的唯一方式,且它是專有的;底層引擎則以 PolyForm Perimeter License 1.0.1 原始碼可取得發布。目前還沒有可供遷移的自我託管發行版,因此請以代管平台為前提規劃。

### 我在代管方案上能託管多少代理?

代理數量上限隨方案層級擴展,從入門方案的小型團隊,到較高層級的大型團隊,企業方案則有客製化上限。代理是持久紀錄而非伺服器,因此建立一個是即時的,閒置的代理不花錢 — 每個代理算作一個計入上限,因此像 Dev Team 這樣的三角色團隊算作三個代理。
