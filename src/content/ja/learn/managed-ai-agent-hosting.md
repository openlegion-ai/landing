# 安全なエージェントフリートのためのマネージドAIエージェントホスティング

あなたが欲しかったのはAIの労働力でした。手に入ったのはDevOpsという2つ目の仕事でした。マネージドAIエージェントホスティングは、その仕事を手放させてくれます。エージェントが必要とするサーバー、隔離、クレデンシャルボルト、予算を運用するので、あなたはそのどれもプロビジョニングする必要がありません。OpenLegionはホスト型Webアプリです。Googleでサインインして始めるだけで、インストールするものも借りる専用VPSもなく、あなたのキーはエージェントが決して触れないボルトに保管され、すべてのエージェントにデフォルトで予算が付きます。あなたは目標を持ち込み、私たちがその下の床を運用します。

<!-- SCHEMA: DefinitionBlock -->

> **マネージドAIエージェントホスティングとは？**
> マネージドAIエージェントホスティングとは、自律AIエージェントが動作するインフラ、すなわちコンテナ、クレデンシャル保管、予算、ネットワーク、制御ダッシュボードをプロビジョニング、隔離、保護、運用するサービスです。これにより、チームはそのインフラを自前で構築・保守することなくエージェントフリートを展開できます。

## TL;DR

- マネージドAIエージェントホスティングは、あなたと稼働中のチームの間の作業を取り除きます。サーバーのセットアップも、インフラのチューニングも、運用すべきボルトもありません。
- エージェントはサーバーではなく永続的なレコードです。作成は即時で、アイドルのエージェントはコストゼロ、1つのワークスペースで数百体を動かせます。
- クレデンシャルはボルトに存在し、モデルの外側で注入されます。モデルが持つのはハンドルだけなので、侵害されたエージェントはそれを読めません。
- エージェント単位の日次・月次予算上限が、暴走するLLM支出を1ドル単位で止めます。モデル利用にマークアップはありません。
- エンジンはPolyForm Perimeter License 1.0.1でソース公開されており、ホスト型プラットフォームはプロプライエタリです。
- プランは月額19ドルからで、初日から課金、7日間の返金保証付き。

## 「ただエージェントを動かす」ことの隠れたコスト

1つのエージェントを立ち上げるのは週末仕事です。信頼できるフリートを運用するのは四半期仕事です。

プロトタイプと本番の間のどこかで、作業は静かに形を変えます。プロンプトのチューニングをやめ、コンテナのチューニングを始めます。エージェントが何を言うべきかを考えるのをやめ、そのAPIキーがどこに存在するか、午前3時に1つがループしたらどうなるか、侵害されたエージェントが他の9つに到達しないようにどう保つかを考え始めます。そのどれも、あなたが当初やろうとした作業ではありません。しかしそのすべてが、エージェントを動かしたまま放置して安全かどうかを決める作業です。

マネージドホスティングは、まさにその層を吸収するために存在します。OpenLegionのホスト型オファリングでは、以下が得られます。

- **ホスト型Webアプリ**。インストールするものも借りる専用VPSもなく、Googleでサインインして始めるだけ。
- **すべてのタスクにサンドボックス実行**。各タスクはオンデマンドで実行されて停止し、エージェントが書いたコードはデフォルトでネットワークアクセスを持ちません。
- **クレデンシャルボルト**。APIキーとOAuthトークンをモデルの完全に外側で保持し、モデルが持つのはハンドルだけです。
- **エージェント単位の予算強制**。ハードカットオフ付きで、ループするエージェントが請求額の不意打ちを生み出せません。
- **制御ダッシュボード**。テンプレートを展開し、エージェントとチャットし、ライブのコストと健全性を監視し、挙動不良のものを一時停止できます。
- **ウェルカムLLMクレジット**。すべての有料プランに付属し、加えて100以上のプロバイダーにわたってマークアップゼロで自分のキーを持ち込むオプションもあります。

## マネージドホスティング vs セルフホスティング：選び方

OpenLegionのプラットフォームはホスト型のみで、その下のエンジンはソース公開されています。以下の比較は、エージェントインフラを自分で運用する場合と、運用してもらう場合との一般的なトレードオフです。

| 検討事項 | セルフホスト（PolyForm Perimeter License 1.0.1） | マネージドホスティング |
|---|---|---|
| 誰がサーバーを運用するか | あなた | OpenLegion |
| セットアップ時間 | あなたのマシンで3コマンド | サインアップしてテンプレートを選ぶ |
| クレデンシャルボルト | あなたが運用する | モデルの外側であなたの代わりに運用 |
| 更新とパッチ適用 | あなたがプルして再デプロイ | あなたの代わりに適用 |
| データ所在地 | 完全にあなたのインフラ上 | 私たちが運用するホスト型プラットフォーム上 |
| 最適な用途 | 規制・エアギャップ・完全な制御 | 今日チームを動かしたいチーム |
| コストモデル | あなた自身のサーバーコスト | 月額19ドルからのフラットプラン |

コンプライアンス、データ所在地、ホストの完全な制御が、それを運用するコストを上回るときはセルフホスティングを選びましょう。今日の午後にエージェントを働かせたく、ボルトやランタイムや更新サイクルを所有したくないときはマネージドホスティングを選びましょう。OpenLegionはローンチ時点でホスト型プラットフォームのみを提供しているため、移行先となるセルフホスト型プラットフォームは存在しません。

## デプロイを押すと何が起きるか

Googleでサインインすればワークスペースは準備完了です。プロビジョニングするものは何もありません。それとともにアシスタントが作成され、アシスタントが必要なチームメイトを作成します。そこから、欲しいチームを記述します。リサーチデスク、セールスパイプライン、コンテンツスタジオなど。すると、プラットフォームが各役割を、独自のメモリ、予算、ツールパーミッションを持つ永続的なレコードとして作成します。

エージェントは[オーケストレーション層](/learn/ai-agent-orchestration)を通じて協調します。作業はゴールからタスク、そしてエージェントへと構成され、イベントによるウェイクとチームメイト間の委任が伴います。すべてのアクションは実行前に単一のポリシーエンジンがチェックするインテントであり、これにより挙動は監査可能に、コストは予測可能に保たれます。エージェントとは、すべてのプランでWebチャット、ProからTelegramとWebhook、Team以上でSlackと受信メールを通じて対話します。

## 自分で構築しなくてよいセキュリティ

エージェントを安全にホストする最も難しい部分は、チームが最も頻繁に飛ばす部分です。失敗するまで目に見えないからです。OpenLegionのプラットフォームは、[AIエージェントセキュリティ](/learn/ai-agent-security)モデルで説明されているのと同じ多層防御を、デフォルトで有効にして強制します。

- すべてのタスクにサンドボックス実行。侵害される長寿命のエージェントプロセスはありません。
- モデルの外側でクレデンシャルを注入するボルト。エージェントは生のキーを決して保持しません。
- どのツール、ファイル、操作を各エージェントが使えるかを統治するエージェント単位のパーミッションマトリックス。
- すべての境界での入力サニタイゼーション、SSRF保護、プロンプトインジェクションハードニング。
- フェイルクローズするエージェント単位の予算上限。

これらは、ハードニングガイドを読んで自分で実装するのではなく、サインアップすることで継承します。その下のランタイムについては、[AIエージェントプラットフォーム](/learn/ai-agent-platform)の概要をご覧ください。

## OpenLegionの見解

市場にある「AIエージェントホスティング」のほとんどは、全員のエージェントを動かす共有プロセスで、キーは設定ファイルに置かれ、まともな予算強制はありません。それはデモには問題なくとも、本番では危険です。実際にあなたにコストを負わせる障害モード、すなわち漏洩したクレデンシャル、暴走コストループ、別のテナントに到達する侵害されたエージェントは、まさに共有インフラが悪化させるものだからです。マネージドホスティングは、自前で構築しなければ得られない隔離とクレデンシャルの安全性を買えるときにのみ、支払う価値があります。私たちの立場は、それらの保証はアップグレードして入るティアではなくデフォルトであるべきだということです。だからこそ、すべてのプランが同じ隔離、同じボルト、そしてすべてのアクションの前段にある同じポリシーエンジンを得ます。

## よくある質問

### マネージドAIエージェントホスティングとは？

マネージドAIエージェントホスティングとは、自律AIエージェントが必要とするインフラ、すなわち隔離された実行、クレデンシャルボルト、予算強制、ネットワーク、制御ダッシュボードをプロビジョニングして運用するサービスです。これにより、チームはそのインフラを構築・保守することなくエージェントフリートを展開して動かせます。OpenLegionではGoogleでサインインして始めるだけで、インストールするものも借りる専用VPSもありません。

### マネージドホスティングは、OpenLegionのセルフホスティングとどう違いますか？

OpenLegionはホスト型Webアプリで、ローンチ時点でセルフホスト型プラットフォームはありません。一般にセルフホスティングは、サーバーを運用し、ボルトを運用し、更新を自分で適用することを意味し、規制環境やエアギャップ環境に適します。マネージドホスティングは、OpenLegionがプラットフォームを運用し、ボルトを運用し、パッチを適用することを意味します。その下のエンジンはPolyForm Perimeter License 1.0.1でソース公開されており、ホスト型プラットフォームはプロプライエタリです。

### 私のAPIキーやウォレットキーを保持するAIエージェントをホストしても安全ですか？

はい、キーがエージェントの内側に決して存在しなければ安全です。OpenLegionでは、APIキーとOAuthトークンはボルトに保持され、モデルの外側で注入されます。モデルが持つのはハンドルだけなので、完全に侵害されたエージェントでもそのシークレットを読んだり持ち出したりできません。OpenLegionはウォレットのキーやエージェントの資金を一切保持しません。

### マネージドAIエージェントホスティングはいくらかかりますか？

無料は$0で1,000回限りのクレジット、カード不要。Proは月額$29で10,000クレジット、Teamは月額$99で35,000クレジット、Enterpriseは$1,500からです。料金には、ホスト型プラットフォーム、クレデンシャルボルト、ダッシュボード、プランに含まれるクレジットが含まれ、支払うべき専用VPSはありません。作業は1クレジット$0.001で計量され、含まれるクレジットは毎月更新され、購入したクレジットパックは失効しません。

### マネージドホスティングを使うのにDockerやDevOpsの知識が必要ですか？

いいえ。OpenLegionはホスト型Webアプリです。Googleでサインインして始めるだけで、インストールするものはありません。あなたはダッシュボードを通じて作業します。欲しいチームを記述すれば、アシスタントが必要なチームメイトを作成します。Docker、Python、サーバー管理はまったく関係ありません。

### 後からマネージドホスティングからセルフホストへ移行できますか？

ローンチ時点ではできません。今日OpenLegionを動かす唯一の方法はホスト型プラットフォームであり、それはプロプライエタリです。その下のエンジンはPolyForm Perimeter License 1.0.1でソース公開されています。移行先となるセルフホスト配布物はまだないため、当面はホスト型プラットフォームを前提に計画してください。

### マネージドプランで何個のエージェントをホストできますか？

エージェントの上限はプランのティアに応じてスケールし、エントリープランの小さなチームから上位ティアの大規模チームまで、エンタープライズ向けにはカスタム上限もあります。エージェントはサーバーではなく永続的なレコードなので、作成は即時でアイドルのエージェントはコストゼロです。各エージェントが上限に対して1エージェントとしてカウントされるので、Dev Teamのような3役割のチームは3エージェントとしてカウントされます。
