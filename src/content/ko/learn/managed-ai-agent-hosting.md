# 안전한 에이전트 플릿을 위한 매니지드 AI 에이전트 호스팅

여러분이 원한 것은 AI 인력이었습니다. 받은 것은 DevOps라는 두 번째 직업이었습니다. 매니지드 AI 에이전트 호스팅은 그 직업을 돌려줍니다. 여러분의 에이전트가 필요로 하는 서버, 격리, 자격 증명 볼트, 예산을 운영하므로, 여러분은 그 무엇도 직접 프로비저닝하지 않습니다. OpenLegion은 호스팅 웹 앱입니다: Google로 로그인하면 시작되고, 설치할 것도 빌릴 전용 VPS도 없으며, 여러분의 키는 에이전트가 결코 건드리지 않는 볼트에 보관되고, 모든 에이전트에 기본적으로 예산이 붙습니다. 여러분은 목표를 가져오고, 그 아래 바닥은 우리가 운영합니다.

> **매니지드 AI 에이전트 호스팅이란 무엇입니까?**
> 매니지드 AI 에이전트 호스팅은 자율 AI 에이전트가 실행되는 인프라, 즉 컨테이너, 자격 증명 저장소, 예산, 네트워킹, 제어 대시보드를 프로비저닝하고, 격리하고, 보안하고, 운영하는 서비스입니다. 그래서 팀은 그 인프라를 직접 구축하거나 유지하지 않고도 에이전트 플릿을 배포할 수 있습니다.

## 핵심 요약

- 매니지드 AI 에이전트 호스팅은 여러분과 실행 중인 플릿 사이의 작업을 제거합니다: 서버 설정도, Docker 튜닝도, 운영할 볼트도 없습니다.
- 에이전트는 서버가 아니라 영속 레코드입니다: 생성은 즉시 끝나고, 유휴 에이전트는 비용이 들지 않으며, 워크스페이스 하나가 수백 개를 운영할 수 있습니다.
- 자격 증명은 볼트에 머물며 모델 외부에서 주입되고 모델은 핸들만 보유하므로, 탈취된 에이전트는 키를 읽을 수 없습니다.
- 모든 에이전트가 자체 예산을 가지며, 모든 작업 단위는 개당 $0.001인 크레딧으로 계량되어 기록되는 웨이크입니다.
- 엔진은 PolyForm Perimeter License 1.0.1로 소스 공개되며, 호스팅 플랫폼은 독점입니다.
- 무료는 $0에 일회성 1,000 크레딧, 카드 불필요이고, Pro는 10,000 크레딧에 $29/월, Team은 35,000 크레딧에 $99/월입니다.

## "그냥 에이전트 하나 실행하기"의 숨은 비용

에이전트 하나를 세우는 일은 주말입니다. 신뢰할 수 있는 플릿을 운영하는 일은 한 분기입니다.

프로토타입과 프로덕션 사이 어딘가에서, 작업은 조용히 모양을 바꿉니다. 프롬프트를 튜닝하기를 멈추고 컨테이너를 튜닝하기 시작합니다. 에이전트가 무슨 말을 해야 하는지를 생각하기를 멈추고, 그것의 API 키가 어디 있는지, 새벽 3시에 하나가 루프에 빠지면 무슨 일이 일어나는지, 탈취된 에이전트가 나머지 아홉에 도달하지 못하게 어떻게 막을지를 생각하기 시작합니다. 그 어느 것도 여러분이 하려던 일이 아닙니다. 그 전부가 에이전트를 켜둔 채로 두어도 안전한지를 결정하는 일입니다.

매니지드 호스팅은 바로 그 레이어를 흡수하기 위해 존재합니다. OpenLegion의 호스팅 제공물로 여러분은 다음을 얻습니다:

- **설치할 것도 빌릴 전용 VPS도 없는 호스팅 웹 앱**, Google로 로그인하면 바로 시작됩니다.
- **모든 작업마다의 샌드박스 실행**, 각 작업은 필요할 때 실행된 뒤 종료되고, 에이전트가 작성한 코드는 기본적으로 네트워크 접근이 없음.
- **자격 증명 볼트**, API 키와 OAuth 토큰을 모델 바깥에 완전히 보관하며 모델은 핸들만 보유.
- **에이전트별 예산 시행**, 하드 컷오프와 함께, 그래서 루프에 빠진 에이전트가 깜짝 청구서를 만들 수 없음.
- **제어 대시보드**, 템플릿을 배포하고, 에이전트와 채팅하고, 라이브 비용과 상태를 지켜보고, 오작동하는 것을 일시 중지.
- **포함 크레딧**, 모든 플랜에 제공되고 매월 갱신되며, 모델은 Smartest, Smart, Normal 프리셋으로 선택.

## 매니지드 호스팅 vs 셀프 호스팅: 선택하는 법

OpenLegion의 플랫폼은 호스팅 전용이며, 그 아래 엔진은 소스 공개로 게시됩니다. 아래 비교는 에이전트 인프라를 직접 운영하는 것과 대신 운영받는 것 사이의 일반적인 트레이드오프입니다.

| 고려 사항 | 셀프 호스팅 (PolyForm Perimeter License 1.0.1) | 매니지드 호스팅 |
|---|---|---|
| 누가 서버를 운영하는가 | 여러분 | OpenLegion |
| 설치 시간 | 여러분 머신에서 세 명령 | Google로 로그인, 설치할 것 없음 |
| 자격 증명 볼트 | 여러분이 운영 | 모델 바깥에서 대신 운영 |
| 업데이트와 패치 | 여러분이 풀하고 재배포 | 대신 적용 |
| 데이터 거주 | 전적으로 여러분 인프라에 | 우리가 운영하는 호스팅 플랫폼에 |
| 적합한 용도 | 규제, 에어 갭, 완전한 통제 | 오늘 당장 팀을 돌리려는 팀 |
| 비용 모델 | 여러분 자신의 서버 비용 | 무료 $0, Pro $29/월, Team $99/월 |

컴플라이언스, 데이터 거주, 또는 호스트에 대한 전적인 통제가 그것을 운영하는 비용을 능가할 때 셀프 호스팅을 선택하십시오. 오늘 오후 에이전트가 일하기를 원하고 볼트, 런타임, 업데이트 주기를 소유하지 않으려 할 때 매니지드 호스팅을 선택하십시오. OpenLegion은 출시 시점에 호스팅 플랫폼만 제공하므로, 옮겨 갈 셀프 호스팅 플랫폼은 없습니다.

## 배포를 누르면 일어나는 일

Google로 로그인하면 워크스페이스가 준비됩니다 — 프로비저닝할 것이 없습니다. 어시스턴트가 함께 만들어지고, 필요한 팀원을 스스로 만듭니다. 거기서부터 여러분이 원하는 팀, 즉 리서치 데스크, 영업 파이프라인, 콘텐츠 스튜디오를 설명하면, 플랫폼이 각 역할을 자체 메모리, 예산, 도구 권한을 갖춘 영속 레코드로 만듭니다.

에이전트는 [오케스트레이션 레이어](/learn/ai-agent-orchestration)를 통해 조율합니다: 작업은 목표 → 태스크 → 에이전트로 구성되며, 이벤트 웨이크와 팀원 간 위임이 함께합니다. 모든 행동은 실행 전에 단일 정책 엔진이 검사하는 인텐트이므로, 동작이 감사 가능하고 비용이 예측 가능하게 유지됩니다. 여러분은 모든 플랜의 웹 채팅으로, Pro부터는 Telegram과 웹훅으로, Team 이상에서는 Slack과 인바운드 이메일로 에이전트와 대화합니다.

## 직접 구축하지 않아도 되는 보안

에이전트를 안전하게 호스팅하는 가장 어려운 부분은 팀이 가장 자주 건너뛰는 부분인데, 실패하기 전까지 보이지 않기 때문입니다. OpenLegion의 매니지드 플레인은 [AI 에이전트 보안](/learn/ai-agent-security) 모델에 설명된 것과 동일한 심층 방어를 기본으로 활성화한 채 시행합니다:

- 탈취될 상주 에이전트 프로세스 없이, 모든 작업마다의 샌드박스 실행.
- 모델 외부에서 자격 증명을 주입하는 자격 증명 볼트, 그래서 에이전트는 원시 키를 결코 쥐지 않음.
- 각 에이전트가 어떤 도구, 파일, 작업을 사용할 수 있는지를 다스리는 에이전트별 권한 매트릭스.
- 모든 경계에서의 입력 새니타이즈, SSRF 보호, 프롬프트 인젝션 하드닝.
- 닫힘으로 실패하는 에이전트별 예산 상한.

여러분은 하드닝 가이드를 읽고 직접 구현하는 것이 아니라 가입함으로써 이것들을 물려받습니다. 그 아래 런타임은 [AI 에이전트 플랫폼](/learn/ai-agent-platform) 개요를 참조하십시오.

### 매니지드 호스팅을 사용하려면 Docker나 DevOps를 알아야 합니까?

아니오. OpenLegion은 호스팅 웹 앱입니다: Google로 로그인하면 시작되며 설치할 것이 없습니다. 여러분은 대시보드를 통해 작업합니다: 원하는 팀을 설명하면 어시스턴트가 필요한 팀원을 만듭니다. Docker, Python, 서버 관리는 아예 관여하지 않습니다.

### 나중에 매니지드 호스팅에서 셀프 호스팅으로 옮길 수 있습니까?

출시 시점에는 불가능합니다. 오늘 OpenLegion을 실행하는 유일한 방법은 호스팅 플랫폼이며 그것은 독점입니다. 그 아래 엔진은 PolyForm Perimeter License 1.0.1로 소스 공개됩니다. 아직 마이그레이션할 셀프 호스팅 배포판이 없으므로, 당분간은 호스팅 플랫폼을 전제로 계획하십시오.

### 매니지드 플랜에서 에이전트를 몇 개나 호스팅할 수 있습니까?

에이전트 한도는 플랜 티어에 따라 확장되며, 엔트리 플랜의 작은 팀부터 상위 티어의 대규모 팀까지, 엔터프라이즈를 위한 커스텀 한도와 함께입니다. 에이전트는 서버가 아니라 영속 레코드이므로 생성이 즉시 끝나고 유휴 에이전트는 비용이 들지 않으며, 각 에이전트가 한도에서 하나로 계산되므로 Dev Team 같은 세 역할 팀은 세 에이전트로 계산됩니다.
