# OpenLegion으로 DeepSeek 기반 에이전트를 안전하게 실행

**DeepSeek 기반 에이전트**는 DeepSeek 모델과 자율 도구 사용을 결합합니다 — 그리고 OpenLegion은 이를 보호하는 AI 에이전트 프레임워크입니다. 볼트에 보관되는 자격 증명, 모든 작업마다 샌드박스 실행, 에이전트별 예산 통제가 기본으로 제공됩니다. 모델은 Smartest, Smart, Normal 프리셋으로 선택하며, 작업은 개당 $0.001인 크레딧으로 계량됩니다.

<!-- SCHEMA: DefinitionBlock -->

> **DeepSeek 기반 에이전트란 무엇입니까?**
> DeepSeek 기반 에이전트는 DeepSeek 모델(예: `deepseek-chat` 또는 `deepseek-coder`)로 구동되는 자율 AI 에이전트입니다. OpenLegion과 같은 AI 에이전트 프레임워크를 통해 배포될 경우, 플랫폼 수준에서 시행되는 작업별 샌드박스 실행과 볼트 보관 자격 증명과 함께 다단계 작업 실행, API 호출, 코드 생성, 입력 처리가 가능합니다.

## 핵심 요약

- **프리셋 라우팅 모델.** OpenLegion은 모든 에이전트를 에이전트별 또는 워크스페이스별로 고른 모델 프리셋(Smartest, Smart, Normal)으로 실행하며, 연결할 제공자 계정이나 엔드포인트가 없습니다.
- **볼트에 보관되는 자격 증명.** 자격 증명은 모델의 컨텍스트에 들어가지 않습니다. 볼트에 보관되어 모델 외부에서 주입되며, 모델은 핸들만 보유합니다.
- **샌드박스 실행.** 각 작업은 필요할 때 실행된 뒤 종료되며, 에이전트가 작성한 코드는 기본적으로 네트워크 접근이 없는 샌드박스에서 실행됩니다.
- **에이전트별 예산 통제.** 모든 에이전트가 자동 하드 컷오프가 있는 자체 크레딧 예산을 가집니다 — 반복 횟수가 예측 불가능한 에이전트 워크로드에 필수적입니다.
- **모델과 무관한 보안.** 프리셋 뒤에 어떤 모델이 있든 OpenLegion은 동일한 [AI 에이전트 보안](/learn/ai-agent-security) 보장을 제공합니다: 볼트 보관 자격 증명, 샌드박스 실행, 모든 행동에 대한 영수증.
- **모델 불가지론.** 동일한 에이전트, 동일한 도구, 동일한 보안 — 앱에서 에이전트의 프리셋을 바꾸면 됩니다. 비용 민감 에이전트 팀에는 더 저렴한 모델이 올바른 선택일 수 있습니다.

## DeepSeek 기반 에이전트에 안전한 프레임워크가 필요한 이유

### 강력한 모델. 넓은 폭발 반경.

도구 접근 권한을 가진 DeepSeek 기반 에이전트는 다음을 할 수 있습니다:
- 작업 공간의 파일을 읽고 수정
- 코드를 생성하고 실행
- API, 데이터베이스, 외부 서비스에 접근(권한에 따라)
- 대용량 컨텍스트에 대한 추론

적절한 [AI 에이전트 런타임](/learn/ai-agent-platform)이 없으면, 자율 에이전트는 또한 다음을 할 수도 있습니다:
- API 키와 자격 증명에 접근 시도
- 미터링되는 엔드포인트에서 무제한 API 비용 누적
- 런타임에 격리가 없으면 다른 에이전트나 호스트에 영향
- 감사되지 않은 워크플로 경로 실행
- 사용자 제공 컨텍스트의 프롬프트 인젝션 벡터에 노출

호스팅 AI 에이전트 플랫폼인 OpenLegion은 세 가지 아키텍처 보장으로 이를 해결합니다:

**볼트에 보관되는 자격 증명.** 자격 증명은 모델의 컨텍스트에 들어가지 않습니다. 볼트에 보관되어 모델 외부에서 주입되며, 모델은 핸들만 보유합니다. 모델이 자격 증명을 찾도록 유도되더라도 실행 내부에는 찾을 것이 없습니다.

**샌드박스 작업 실행.** 각 작업은 필요할 때 실행된 뒤 종료되며, 에이전트가 작성한 코드는 기본적으로 네트워크 접근이 없는 샌드박스에서 실행됩니다. 탈취된 에이전트는 다른 에이전트, 플랫폼, 자격 증명 볼트에 영향을 줄 수 없습니다.

**에이전트별 예산 시행.** 모든 에이전트가 자동 하드 컷오프로 시행되는 자체 크레딧 예산을 가집니다. 어떤 에이전트도 하룻밤 사이에 크레딧을 태울 수 없습니다.

## DeepSeek 모델 구성 참고사항

DeepSeek는 `deepseek-chat`, `deepseek-coder` 같은 모델과 주기적인 추론 중심 릴리스를 발표합니다. 정확한 모델 라인업과 가격은 시간이 지남에 따라 변경됩니다. 현재 목록은 [DeepSeek 문서](https://api-docs.deepseek.com/)를 참조하십시오. 에이전트 워크로드를 위한 주요 실무적 고려사항:

- **라우팅.** OpenLegion은 프리셋으로 라우팅합니다. 에이전트에 Smartest, Smart, Normal 중 하나를 고르면 플랫폼이 그 뒤의 모델을 실행하며, 관리할 모델 ID나 애그리게이터 계정이 없습니다.
- **컨텍스트 윈도우와 가격**은 모델마다 다릅니다. 현재 토큰당 비용은 DeepSeek 문서를 확인하십시오. OpenLegion의 에이전트별 예산은 모델에 관계없이 안전망 역할을 합니다.
- **오픈 가중치.** 일부 DeepSeek 모델 라인은 오픈 가중치를 공개했으므로 팀이 Ollama나 vLLM으로 자체 GPU에서 실행할 수 있습니다. OpenLegion은 호스팅형이며 선택한 프리셋 뒤의 모델을 실행합니다 — 어느 쪽이든 보안 보장은 모든 작업에 동일하게 적용됩니다.

## OpenLegion에서 DeepSeek 기반 에이전트 실행 방법

에이전트 설정은 호스팅 앱에서 약 30초가 걸립니다 — 구성 파일도, YAML 편집도, 설치할 것도 없습니다. Google로 로그인하면 첫 에이전트가 준비됩니다.

### 1단계: LLM 제공자 선택

선택할 제공자가 없습니다: OpenLegion이 모델을 대신 실행합니다. 대신 에이전트별 또는 워크스페이스별로 프리셋 — Smartest, Smart, Normal — 을 고릅니다. 이는 OpenLegion의 모든 [에이전트 조율](/learn/ai-agent-orchestration)을 구동하는 동일한 모델 시스템입니다.

### 2단계: API 키 제공

붙여넣을 모델 API 키도, 시작에 필요한 카드도 없습니다. 에이전트가 사용하는 도구를 위해 추가하는 자격 증명은 볼트에 보관되어 모델 외부에서 주입되므로, 에이전트는 핸들만 보유하며 원시 키를 절대 보지 않습니다.

### 3단계: 모델 선택

해당 에이전트 또는 워크스페이스 전체에 대해 원하는 프리셋(Smartest, Smart, Normal)을 고르십시오. 완료입니다. 에이전트는 이제 볼트 보관 자격 증명, 작업별 샌드박스 실행, 예산 시행과 함께 실행됩니다 — OpenLegion이 실행하는 모든 모델에 적용되는 동일한 보안 스택입니다.

이것이 전부입니다. 앱이 모델을, 볼트가 자격 증명을, 플랫폼이 샌드박싱과 예산을 처리합니다.

### 오픈 가중치로 DeepSeek 로컬 실행

팀은 Ollama, vLLM 또는 다른 추론 서버로 자체 GPU에서 DeepSeek 오픈 가중치를 실행할 수 있고, 그러면 추론이 온프레미스에 머뭅니다. OpenLegion 자체는 호스팅형입니다: 셀프 호스팅 옵션도, 가리킬 로컬 엔드포인트도 없으며, 각 프리셋 뒤의 모델은 플랫폼에서 실행됩니다. OpenLegion이 기여하는 것은 모델 주변의 모든 것입니다 — 샌드박스 실행, 도구 접근 통제, 위임, 모든 행동에 대한 영수증.

### 모델 전환 — Claude 또는 GPT의 대안으로서 DeepSeek

동일한 작업에서 더 저렴한 모델을 프런티어 모델과 비교하고 싶습니까? 앱에서 에이전트의 프리셋을 변경하십시오. 동일한 에이전트, 동일한 도구, 동일한 보안 — 다른 모델. 제공자 전반의 분석은 [AI 에이전트 프레임워크 비교](/learn/ai-agent-frameworks)를 참조하십시오.

## DeepSeek 기반 에이전트 워크플로

### 긴 컨텍스트로 리포지토리 규모의 에이전트 구현

최신 DeepSeek 계열 모델은 큰 컨텍스트 윈도우를 지원하여 다음과 같은 에이전트 워크플로를 가능하게 합니다:

- **전체 리포지토리 코드 리뷰**를 한 번에 수행(컨텍스트 윈도우가 허용할 때)
- **크로스 파일 리팩토링**과 광범위한 의존성 인식
- 더 큰 프로젝트 컨텍스트로부터의 **문서 생성**
- 코드베이스 전반에 걸친 **보안 감사**

OpenLegion은 이러한 긴 컨텍스트 작업을 제한합니다: 각 작업은 필요할 때 실행된 뒤 종료되고, 모든 웨이크는 정책 엔진이 검사하고 계량하며, 에이전트별 예산은 단일 초대형 프롬프트가 전체 월별 예산을 소진하는 것을 방지합니다.

### 하드 컷오프를 통한 비용 예측성

DeepSeek 모델은 역사적으로 서구의 프런티어 대안보다 낮은 가격을 책정해 왔으며, 이는 반복이 많은 에이전트 워크로드에 매력적입니다. 그러나 "호출당 더 저렴함"도 에이전트가 자유롭게 반복하면 "총합으로 비쌈"이 될 수 있습니다. OpenLegion의 에이전트별 크레딧 예산과 하드 컷오프는 비용 급증이 팀 전반으로 번지지 않도록 막습니다.

## DeepSeek 기반 에이전트를 위한 보안 고려사항

### 오픈 가중치는 기능이자 위험 표면

DeepSeek의 오픈 가중치 릴리스는 셀프 호스팅 배포와 생태계 투명성에 강한 이점입니다. 또한 다음을 의미합니다:

- **파인 튜닝된 변종이 증가할 것입니다.** 모두가 정렬되거나 안전성 테스트를 거치지는 않을 것입니다. OpenLegion의 샌드박스 실행과 도구 제한은 프리셋 뒤에 어떤 모델이 있든 적용됩니다.
- **오픈 가중치에서는 적대적 연구가 더 쉽습니다.** 오픈 가중치 모델을 실행하는 에이전트는 모델 수준의 정렬뿐만 아니라 [심층 방어](/learn/ai-agent-security)의 혜택을 받습니다: 샌드박스 실행, 제한된 실행, 명시적 도구 권한.
- **공급망 위생.** Hugging Face 또는 다른 소스에서 오픈 가중치를 다운로드할 때는 체크섬과 출처를 검증해야 합니다. 어떤 모델 바이너리를 실행하는지 문서화하십시오.

### 긴 컨텍스트는 프롬프트 인젝션 표면을 넓힙니다

큰 컨텍스트 윈도우는 큰 잠재적 프롬프트 인젝션 표면입니다. 전체 코드베이스를 처리하는 에이전트는 모든 주석, 모든 문자열 리터럴, 모든 README를 처리합니다 — 그중 어느 것도 적대적 명령을 포함할 수 있습니다.

OpenLegion의 방어: 모든 행동 앞에 놓인 단일 정책 엔진, 에이전트별 도구 권한, 인젝션이 키를 유출할 수 없게 하는 볼트 보관 자격 증명, 신뢰할 수 없는 콘텐츠에 따라 행동하기 전의 승인 경계. 이는 인젝션이 성공하더라도 피해를 제한합니다.

### 지정학적 고려사항

수출 통제, 데이터 주권 요건 또는 공급망 컴플라이언스를 받는 조직의 경우, 배포 모드가 중요합니다:

- **API 모드:** 데이터가 DeepSeek의 호스팅 인프라를 거칩니다.
- **셀프 호스팅 모드(오픈 가중치):** 데이터가 본인 인프라에 머뭅니다. API 의존성을 완전히 제거합니다.
- **애그리게이터/추론 제공자 모드:** 데이터가 제공자의 인프라를 거칩니다(제공자에 따라 다름).

OpenLegion은 호스팅형이므로 추론은 플랫폼에서 실행되며, 모든 플랜에 동일한 [AI 에이전트 보안](/learn/ai-agent-security) 보장이 적용됩니다.

| **셀프 호스팅 가능** | 예(오픈 가중치 릴리스) | 불가 | 불가 |
| **가격 포지셔닝** | 일반적으로 토큰당 더 저렴 | 프리미엄 | 프리미엄 |
| **에이전트 프레임워크 지원** | LiteLLM 통한 (100+ 제공자) | 네이티브 + LiteLLM | 네이티브 + LiteLLM |
| **OpenLegion 지원** | 프리셋으로 선택 | 프리셋으로 선택 | 프리셋으로 선택 |

*OpenLegion은 실행하는 모든 모델에 동일한 보안 보장을 적용합니다. 앱에서 에이전트의 프리셋을 전환하십시오 — 동일한 에이전트, 동일한 보안, 다른 모델. 상세 분석은 [전체 프레임워크 비교](/comparison)를 참조하십시오.*

## OpenLegion으로 DeepSeek 기반 에이전트를 실행해야 하는 대상

**많은 에이전트를 운영하는 비용 민감 팀.** 토큰당 더 낮은 가격은 동일한 예산으로 더 많은 에이전트를 더 자주 실행할 수 있음을 의미합니다. OpenLegion의 에이전트별 비용 통제는 "호출당 더 저렴함"이 "총합으로 더 비쌈"이 되지 않도록 막습니다.

**자격 증명을 모델에서 떼어놓아야 하는 팀.** OpenLegion은 모든 자격 증명을 볼트에 보관하고 모델 외부에서 주입하므로, 모델은 핸들만 보유하며 키를 결코 보지 않습니다.

**모델 품질과 비용을 저울질하는 팀.** OpenLegion의 모델 불가지론 아키텍처는 동일한 에이전트 팀을 서로 다른 프리셋에서 실행해 작업당 품질, 비용, 지연 시간을 비교할 수 있게 해주며, 각 작업의 정확한 비용이 표시됩니다. 프레임워크 수준의 비교는 [OpenLegion vs OpenClaw](/comparison/openclaw) 및 [OpenLegion vs LangGraph](/comparison/langgraph)를 참조하십시오.

## 자주 묻는 질문

### DeepSeek 기반 에이전트란 무엇입니까?

DeepSeek 기반 에이전트는 격리, 자격 증명, 도구, 예산, 조율을 제공하는 에이전트 프레임워크 하에서 실행되는 DeepSeek 모델(예: `deepseek-chat` 또는 `deepseek-coder`)로 구동되는 자율 AI 에이전트입니다. OpenLegion은 그러한 프레임워크 중 하나로, 선택한 어떤 모델 프리셋에든 작업별 샌드박스 실행, 볼트 보관 자격 증명, 에이전트별 크레딧 예산을 더합니다.

### OpenLegion은 DeepSeek를 지원합니까?

OpenLegion이 모델을 대신 실행하므로 제공자를 선택할 일이 없습니다. 대신 에이전트별 또는 워크스페이스별로 프리셋 — Smartest, Smart, Normal — 을 고르면 플랫폼이 그 뒤의 모델을 실행합니다. 붙여넣을 API 키도, 구성할 애그리게이터 계정도, 세울 추론 서버도 없습니다. 작업은 개당 $0.001인 크레딧으로 계량되며 각 작업의 정확한 비용이 표시됩니다.

### DeepSeek 기반 에이전트를 안전하게 실행하려면 어떻게 합니까?

OpenLegion은 모든 에이전트에 세 가지 보안 레이어를 제공합니다: 볼트 보관 자격 증명(자격 증명이 모델의 컨텍스트에 들어가지 않으며 — 볼트에 머물고 모델 외부에서 주입됨), 작업별 샌드박스 실행(각 작업이 필요할 때 실행된 뒤 종료되고, 에이전트가 작성한 코드는 기본 네트워크 접근이 없음), 에이전트별 예산 시행(자동 하드 컷오프가 있는 자체 크레딧 예산). 에이전트를 만들고 프리셋을 고르면 보안 스택이 자동으로 적용됩니다.

### 에이전트에 Claude나 GPT보다 DeepSeek가 더 낫습니까?

작업에 따라 다릅니다. DeepSeek 계열 모델은 일반적으로 Claude와 GPT보다 낮게 가격을 책정하며 많은 벤치마크에서 경쟁력 있는 성능을 보이지만, 구체적 기능은 모델마다 다릅니다. 에이전트 워크로드의 경우 선택은 작업 요건, 비용 제약, 데이터 거주 요건에 따라 다릅니다. OpenLegion은 실행하는 모든 모델에 동일한 보안 보장을 적용합니다 — 동일한 워크플로에서 프리셋을 나란히 평가할 수 있습니다.

### OpenLegion으로 DeepSeek를 셀프 호스팅할 수 있습니까?

출시 시점에는 불가능합니다. OpenLegion은 호스팅 웹 앱이며, 셀프 호스팅 옵션도 가리킬 로컬 엔드포인트도 없습니다. 추론을 자체 GPU 인프라에 유지해야 하는 팀은 OpenLegion과 별개로 Ollama나 vLLM으로 오픈 가중치를 실행할 수 있습니다. 플랫폼에서는 프리셋을 고르며, 샌드박스 실행, 도구 접근 통제, 위임, 에이전트별 예산이 모두 적용됩니다.

### 에이전트 워크로드에서 DeepSeek 가격은 어떻게 비교됩니까?

DeepSeek는 일반적으로 토큰당 기준에서 서구 프런티어 모델보다 낮게 가격을 책정합니다. 많은 반복적인 API 호출이 있는 에이전트 워크로드의 경우 비용 차이가 누적됩니다. OpenLegion의 에이전트별 예산 통제 — 하드 컷오프가 있는 에이전트별 크레딧 예산 — 는 에이전트가 자유롭게 반복할 때 호출당 더 저렴함이 총합으로 비싸지는 것을 막아줍니다.

### DeepSeek는 AI 에이전트를 위한 Claude의 좋은 대안입니까?

DeepSeek는 비용 민감 에이전트 워크로드에 매력적인 대안이 될 수 있습니다. OpenLegion은 실행하는 모든 모델에 동일한 보안 보장을 적용하므로 동일한 워크플로에서 프리셋을 나란히 평가할 수 있으며, 에이전트나 인프라를 변경하지 않고 앱에서 전환할 수 있습니다.

### 중국 AI 모델에서 에이전트를 실행하는 것이 안전합니까?

안전성 질문은 배포 모델에 달려 있습니다. 셀프 호스팅, 오픈 가중치 DeepSeek 에이전트는 데이터가 본인 인프라를 떠나지 않음을 의미합니다. API 모드는 데이터를 DeepSeek의 호스팅 서버를 통해 라우팅합니다. OpenLegion은 호스팅형이며 선택한 프리셋 뒤의 모델을 실행하고, 모든 플랜에 동일한 보안 보장이 적용됩니다. 데이터 주권 요건이 있는 조직의 경우, 오픈 가중치로의 셀프 호스팅 배포는 추론을 본인 인프라에 유지합니다.

### DeepSeek의 긴 컨텍스트 윈도우가 에이전트에 어떻게 유용합니까?

큰 컨텍스트 윈도우는 청킹이나 검색 증강 없이 한 번에 전체 코드베이스, 완전한 문서 세트, 긴 대화 기록을 처리하는 에이전트 워크플로를 가능하게 합니다. OpenLegion의 제한된 실행과 에이전트별 예산은 어떤 모델이 사용되든 비싼 긴 컨텍스트 프롬프트가 한도를 초과하지 않도록 방지합니다.
