# 面向安全智能体集群的托管式 AI 智能体托管

你想要的是一支 AI 劳动力大军。结果你得到的却是一份 DevOps 的兼职。托管式 AI 智能体托管把这份工作还给你。它运行你的智能体所需的服务器、隔离、凭证密钥库和预算，因此这些你一概无需自行配置。OpenLegion 是一个托管 Web 应用：用 Google 登录即可开始，没有东西需要安装，也不必租用专用 VPS；你的密钥保管在智能体从不接触的密钥库里，每个智能体默认都有预算。你只需带来一个目标；底层的运维由我们来跑。

<!-- SCHEMA: DefinitionBlock -->

> **什么是托管式 AI 智能体托管？**
> 托管式 AI 智能体托管是一项服务，它负责配置、隔离、保护和运维自主 AI 智能体所运行的基础设施：容器、凭证存储、预算、网络和一个控制仪表板，从而让团队无需自行构建或维护这些基础设施即可部署智能体集群。

## 摘要

- 托管式 AI 智能体托管消除了你与一支运行中的集群之间的工作：无需服务器搭建、无需 Docker 调优、无需运维密钥库。
- 智能体是持久记录而非服务器：创建一个是即时的，闲置的智能体不花钱，一个工作区可以容纳数百个。
- 凭证存放在密钥库中，并在模型之外注入，模型自始至终只持有一个句柄，因此被攻陷的智能体无法读取它们。
- 每个智能体都有自己的预算，每一份工作都是一次有记录的唤醒，按每积分 $0.001 计量。
- 引擎在 PolyForm Perimeter License 1.0.1 下以源码可用方式发布；托管平台本身是专有的。
- 免费版 $0，含 1,000 一次性积分且无需绑卡；Pro 每月 $29，含 10,000 积分；Team 每月 $99，含 35,000 积分。

## 「随便跑个智能体」的隐藏成本

搭起一个智能体是一个周末的事。运行一支你能信任的集群则是一个季度的事。

在原型和生产之间的某个地方，工作悄然改变了形态。你不再调优提示，而开始调优容器。你不再思考智能体该说什么，而开始思考它的 API 密钥放在哪里、当某个智能体在凌晨 3 点陷入循环时会发生什么、以及如何阻止一个被攻陷的智能体波及其他九个。这些都不是你最初要做的工作。但它们全都决定着这些智能体是否可以安全地放任运行。

托管服务的存在，正是为了吸收这一层。借助 OpenLegion 的托管产品，你将获得：

- **一个托管 Web 应用**，没有东西需要安装，也不必租用专用 VPS —— 用 Google 登录即可开始。
- **每个任务一次沙箱化运行** —— 每个任务按需运行然后停止，智能体编写的代码默认没有网络访问。
- **一个凭证密钥库**，把 API 密钥和 OAuth 令牌完全保管在模型之外，模型自始至终只持有一个句柄。
- **单智能体预算执行**，带硬性截止，因此一个陷入循环的智能体无法生成意外账单。
- **一个控制仪表板**，用于部署模板、与智能体对话、实时观察成本和健康状况，并暂停任何行为异常的智能体。
- **套餐内含积分**，每个套餐都有并按月刷新，模型通过预设选择 —— 最智能、智能或普通。

## 托管服务 vs 自托管：如何选择

OpenLegion 的平台仅以托管方式提供，底层引擎则以源码可用方式发布。下表比较的是"自己运维智能体基础设施"与"让别人替你运维"之间的一般权衡。

| 考量 | 自托管（PolyForm Perimeter License 1.0.1） | 托管服务 |
|---|---|---|
| 谁来运维服务器 | 你 | OpenLegion |
| 搭建时间 | 在你机器上三条命令 | 用 Google 登录，无需安装任何东西 |
| 凭证密钥库 | 由你运维 | 为你运维，位于模型之外 |
| 更新与打补丁 | 你拉取并重新部署 | 为你应用 |
| 数据驻留 | 完全在你的基础设施上 | 在我们运行的托管平台上 |
| 最适合 | 受监管、气隙隔离、完全掌控 | 想要今天就让团队跑起来的用户 |
| 成本模型 | 你自己的服务器成本 | 免费 $0、Pro $29/月、Team $99/月 |

当合规、数据驻留或对主机的完全掌控胜过运维成本时，选择自托管。当你想让智能体今天下午就开始工作、又不愿拥有一个密钥库、一套运行时和一套更新节奏时，选择托管服务。OpenLegion 在发布时只提供托管平台，因此并不存在可迁移过去的自托管平台。

## 当你点击部署时会发生什么

用 Google 登录，你的工作区就准备好了 —— 没有任何东西需要配置。系统会随之创建一个助手，由它创建所需的队友。从那里开始，你描述想要的团队（一个研究台、一条销售管道、一个内容工作室），平台便把每个角色创建成一条持久记录，带有自己的记忆、预算和工具权限。

这些智能体通过 [编排层](/learn/ai-agent-orchestration) 进行协调：工作按目标 → 任务 → 智能体组织，配合事件唤醒和队友之间的委派。每个动作在发生之前都是由统一策略引擎校验的意图，这让行为保持可审计、成本保持可预测。所有套餐都可以在 Web 聊天中与智能体对话，Pro 起支持 Telegram 和 webhook，Team 及以上支持 Slack 和入站邮件。

## 无需你自行构建的安全

安全托管智能体最难的部分，恰恰是团队最常跳过的部分，因为它在失效之前都是隐形的。OpenLegion 的托管平面强制执行 [AI 智能体安全](/learn/ai-agent-security) 模型中描述的同一套纵深防御，默认启用：

- 每个任务一次沙箱化运行，没有长期驻留的智能体进程可供攻陷。
- 一个在模型之外注入凭证的密钥库，因此智能体从不持有原始密钥。
- 一个单智能体权限矩阵，管理每个智能体可以使用哪些工具、文件和操作。
- 在每一道边界进行输入清洗、SSRF 防护和提示注入加固。
- 失败即关闭的单智能体预算上限。

你通过注册就继承了这些，而不是读一份加固指南再自己实现。关于底层的运行时，参见 [AI 智能体平台](/learn/ai-agent-platform) 概述。

## 常见问题

### 什么是托管式 AI 智能体托管？

托管式 AI 智能体托管是一项服务，它配置并运维自主 AI 智能体所需的基础设施：隔离容器、一个凭证密钥库、预算执行、网络和一个控制仪表板，从而让团队无需构建或维护这些基础设施即可部署和运行智能体集群。使用 OpenLegion，你只需用 Google 登录即可开始 —— 没有东西需要安装，也不必租用专用 VPS。

### 托管服务与自托管 OpenLegion 有何不同？

OpenLegion 是一个托管 Web 应用，发布时并不存在自托管平台。一般意义上的自托管意味着你自己运行服务器、运维密钥库并应用更新，这适合受监管或气隙隔离的环境。托管服务意味着 OpenLegion 运行平台、运维密钥库并为其打补丁。底层引擎在 PolyForm Perimeter License 1.0.1 下以源码可用方式发布；托管平台是专有的。

### 托管持有我的 API 和钱包密钥的 AI 智能体安全吗？

安全，前提是密钥从不存在于智能体内部。在 OpenLegion 上，API 密钥和 OAuth 令牌保管在密钥库中，并在模型之外注入，模型自始至终只持有一个句柄，因此即使一个被完全攻陷的智能体也无法读取或窃取该机密。OpenLegion 完全不持有钱包密钥或智能体资金。

### 托管式 AI 智能体托管要花多少钱？

免费版 $0，含 1,000 一次性积分且无需绑卡；Pro 每月 $29，含 10,000 积分；Team 每月 $99，含 35,000 积分；企业版 $1,500 起。该费用涵盖托管平台、凭证密钥库、仪表板以及套餐内含的积分 —— 没有专用 VPS 需要付费。工作按积分计量，每积分 $0.001，套餐内积分按月刷新，另行购买的积分包永不过期。

### 使用托管服务需要懂 Docker 或 DevOps 吗？

不需要。OpenLegion 是一个托管 Web 应用：用 Google 登录即可开始 —— 没有东西需要安装。你只需通过仪表板操作：描述你想要的团队，助手就会创建所需的队友。Docker、Python 和服务器管理完全不在其中。

### 我以后可以从托管服务迁移到自托管吗？

发布时还不行。托管平台是目前运行 OpenLegion 的唯一方式，而且它是专有的；底层引擎在 PolyForm Perimeter License 1.0.1 下以源码可用方式发布。目前还没有可迁移过去的自托管发行版，因此请按托管平台来规划。

### 在托管套餐上我可以托管多少个智能体？

智能体数量上限随套餐层级扩展，从入门套餐的小团队到更高层级的大型团队，企业级可定制上限。智能体是持久记录而非服务器，因此创建一个是即时的、闲置的智能体不花钱 —— 每个智能体计为一个，因此像开发团队这样的三角色团队计为三个智能体。
