# Managed AI Agent Hosting สำหรับฝูงเอเจนต์ที่ปลอดภัย

คุณอยากได้แรงงาน AI สิ่งที่คุณได้คืองานที่สองในด้าน DevOps Managed AI agent hosting ส่งงานนั้นคืนให้ มันรันเซิร์ฟเวอร์, การแยก, vault ข้อมูลรับรอง และงบประมาณที่เอเจนต์ของคุณต้องการ ดังนั้นคุณไม่ต้อง provision อะไรเองเลย OpenLegion เป็นเว็บแอปที่โฮสต์ให้: เข้าสู่ระบบด้วย Google แล้วเริ่มได้เลย ไม่มีอะไรต้องติดตั้งและไม่ต้องเช่า VPS เฉพาะ, เก็บคีย์ของคุณไว้ใน vault ที่เอเจนต์ไม่เคยแตะ และจำกัดการใช้จ่ายรายเอเจนต์เป็นค่าเริ่มต้น คุณนำเป้าหมายและคีย์มา เรารันพื้นฐานข้างใต้ให้

> **Managed AI agent hosting คืออะไร**
> Managed AI agent hosting คือบริการที่ provision, แยก, รักษาความปลอดภัย และดำเนินการโครงสร้างพื้นฐานที่ AI agent อัตโนมัติรันอยู่: คอนเทนเนอร์, ที่เก็บข้อมูลรับรอง, งบประมาณ, เครือข่าย และแดชบอร์ดควบคุม เพื่อให้ทีมดีพลอยฝูงเอเจนต์ได้โดยไม่ต้องสร้างหรือดูแลโครงสร้างพื้นฐานนั้นเอง

## TL;DR

- Managed AI agent hosting ขจัดงานระหว่างคุณกับทีมที่รันอยู่: ไม่ต้องตั้งค่าเซิร์ฟเวอร์, ไม่ต้องจูน Docker, ไม่มี vault ให้ดำเนินการ
- เอเจนต์เป็นเรคคอร์ดถาวร ไม่ใช่เซิร์ฟเวอร์: การสร้างเกิดขึ้นทันที เอเจนต์ที่ว่างไม่มีค่าใช้จ่าย และ workspace เดียวรันได้เป็นร้อยตัว
- ข้อมูลรับรองอยู่ใน vault และถูกฉีดเข้าไปนอกโมเดล ซึ่งถือเพียง handle เท่านั้น ดังนั้นเอเจนต์ที่ถูกบุกรุกอ่านมันไม่ได้
- เอเจนต์ทุกตัวมีงบประมาณของตัวเอง และทุกหน่วยงานคือการปลุกที่ถูกบันทึกและคิดเป็นเครดิต เครดิตละ $0.001
- เอนจินเผยแพร่แบบ source-available ภายใต้ PolyForm Perimeter License 1.0.1; แพลตฟอร์มที่โฮสต์ให้เป็นกรรมสิทธิ์
- แพลนฟรีคือ $0 พร้อม 1,000 เครดิตครั้งเดียวโดยไม่ต้องใช้บัตร; Pro คือ $29/เดือนพร้อม 10,000 เครดิต; Team คือ $99/เดือนพร้อม 35,000

## ต้นทุนที่ซ่อนอยู่ของ "แค่รันเอเจนต์"

การตั้งเอเจนต์หนึ่งตัวใช้เวลาสุดสัปดาห์ การรันฝูงที่คุณไว้ใจได้ใช้เวลาหนึ่งไตรมาส

ที่ไหนสักแห่งระหว่างต้นแบบกับโปรดักชัน งานค่อย ๆ เปลี่ยนรูปร่างอย่างเงียบ ๆ คุณเลิกจูน prompt แล้วเริ่มจูนคอนเทนเนอร์ คุณเลิกคิดว่าเอเจนต์ควรพูดอะไร แล้วเริ่มคิดว่า API key ของมันอยู่ที่ไหน, จะเกิดอะไรเมื่อมันวนลูปตอนตีสาม และจะกันเอเจนต์ที่ถูกบุกรุกไม่ให้เข้าถึงอีกเก้าตัวได้อย่างไร ไม่มีสิ่งเหล่านั้นเลยที่เป็นงานที่คุณตั้งใจจะทำ แต่ทั้งหมดคืองานที่ตัดสินว่าเอเจนต์ปลอดภัยพอที่จะปล่อยทิ้งไว้ให้รันหรือไม่

managed hosting มีอยู่เพื่อรับชั้นนั้นไปทำแทนพอดี ด้วยข้อเสนอแบบโฮสต์ของ OpenLegion คุณจะได้:

- **เว็บแอปที่โฮสต์ให้** ที่ไม่มีอะไรต้องติดตั้งและไม่ต้องเช่า VPS เฉพาะ — เข้าสู่ระบบด้วย Google แล้วเริ่มได้เลย
- **การรันในแซนด์บ็อกซ์สำหรับทุกงาน** — แต่ละงานรันตามต้องการแล้วหยุด และโค้ดที่เอเจนต์เขียนไม่มีการเข้าถึงเครือข่ายเป็นค่าเริ่มต้น
- **vault ข้อมูลรับรอง** ที่ถือ API key และ OAuth token ไว้นอกโมเดลโดยสิ้นเชิง ซึ่งถือเพียง handle เท่านั้น
- **การบังคับงบประมาณรายเอเจนต์** พร้อมการตัดเข้มงวด ดังนั้นเอเจนต์ที่วนลูปสร้างใบแจ้งหนี้เซอร์ไพรส์ไม่ได้
- **แดชบอร์ดควบคุม** เพื่อดีพลอยเทมเพลต, แชตกับเอเจนต์, ดูต้นทุนและสุขภาพแบบสด และพักสิ่งที่ทำตัวไม่ดี
- **เครดิตที่รวมมา** ในทุกแพลน รีเฟรชรายเดือน โดยโมเดลถูกเลือกด้วยพรีเซ็ต — Smartest, Smart หรือ Normal

## Managed Hosting vs Self-Hosting: เลือกอย่างไร

OpenLegion ส่งเอนจินเดียวกันสองแบบ ดังนั้นการตัดสินใจจึงเกี่ยวกับว่าใครรันเครื่อง ไม่ใช่ว่าเวอร์ชันไหนทรงความสามารถกว่า

| ข้อพิจารณา | Self-hosted (PolyForm Perimeter License 1.0.1) | Managed hosting |
|---|---|---|
| ใครรันเซิร์ฟเวอร์ | คุณ | OpenLegion |
| เวลาตั้งค่า | สามคำสั่งบนเครื่องของคุณ | เข้าสู่ระบบด้วย Google ไม่ต้องติดตั้งอะไร |
| vault ข้อมูลรับรอง | คุณดำเนินการเอง | ดำเนินการให้ นอกโมเดล |
| การอัปเดตและแพตช์ | คุณ pull และ redeploy | ทำให้คุณ |
| ที่อยู่ของข้อมูล | บนโครงสร้างพื้นฐานของคุณทั้งหมด | บนแพลตฟอร์มที่โฮสต์ให้ซึ่งเราดำเนินการ |
| เหมาะกับ | ถูกกำกับดูแล, air-gapped, ควบคุมเต็มที่ | ทีมที่อยากให้ทีมเอเจนต์รันวันนี้ |
| โมเดลต้นทุน | ต้นทุนเซิร์ฟเวอร์ของคุณเอง | ฟรี $0, Pro $29/เดือน, Team $99/เดือน |

เลือก self-host เมื่อการปฏิบัติตาม, ที่อยู่ของข้อมูล หรือการควบคุมโฮสต์เต็มที่มีน้ำหนักมากกว่าต้นทุนการรันมัน เลือก managed hosting เมื่อคุณอยากให้เอเจนต์ทำงานบ่ายนี้และไม่อยากเป็นเจ้าของ vault, container runtime และจังหวะการอัปเดต OpenLegion เสนอเฉพาะแพลตฟอร์มที่โฮสต์ให้ตอนเปิดตัว จึงไม่มีแพลตฟอร์ม self-host ให้ย้ายไป

## เกิดอะไรขึ้นเมื่อคุณกด Deploy

เข้าสู่ระบบด้วย Google แล้ว workspace ของคุณก็พร้อม — ไม่มีอะไรต้อง provision ผู้ช่วยถูกสร้างขึ้นพร้อมกัน และมันสร้างเพื่อนร่วมทีมที่ต้องการ จากนั้นคุณอธิบายทีมที่คุณต้องการ (โต๊ะวิจัย, ไปป์ไลน์การขาย, สตูดิโอคอนเทนต์) แล้วแพลตฟอร์มจะสร้างแต่ละบทบาทเป็นเรคคอร์ดถาวรพร้อมหน่วยความจำ, งบประมาณ และสิทธิ์เครื่องมือของตัวเอง

เอเจนต์ประสานงานผ่าน[ชั้นการจัดวง](/learn/ai-agent-orchestration): งานถูกจัดเป็นเป้าหมาย → งาน → เอเจนต์ พร้อมการปลุกด้วย event และการมอบหมายระหว่างเพื่อนร่วมทีม ทุกการกระทำเป็นเจตนาที่ policy engine เดียวตรวจสอบก่อนเกิดขึ้น ซึ่งทำให้พฤติกรรมตรวจสอบได้และต้นทุนคาดเดาได้ คุณคุยกับเอเจนต์ผ่านแชตบนเว็บในทุกแพลน, Telegram และ webhook ตั้งแต่ Pro หรือ Slack และอีเมลขาเข้าบน Team ขึ้นไป

## ความปลอดภัยที่คุณไม่ต้องสร้างเอง

ส่วนที่ยากที่สุดของการโฮสต์เอเจนต์อย่างปลอดภัยคือส่วนที่ทีมมักข้ามมากที่สุด เพราะมันมองไม่เห็นจนกว่าจะล้มเหลว ระนาบแบบจัดการให้ของ OpenLegion บังคับใช้ defense-in-depth แบบเดียวกับที่อธิบายไว้ในโมเดล[ความปลอดภัย AI agent](/learn/ai-agent-security) เปิดใช้งานเป็นค่าเริ่มต้น:

- การรันในแซนด์บ็อกซ์สำหรับทุกงาน โดยไม่มีโพรเซสเอเจนต์ที่อยู่ยาวให้บุกรุก
- vault ข้อมูลรับรองที่ฉีดข้อมูลรับรองนอกโมเดล ดังนั้นเอเจนต์ไม่เคยถือคีย์ดิบ
- เมทริกซ์สิทธิ์รายเอเจนต์ที่กำกับว่าเอเจนต์แต่ละตัวใช้เครื่องมือ, ไฟล์ และการดำเนินการใดได้
- การ sanitize input, การป้องกัน SSRF และการ harden prompt-injection ที่ทุกขอบเขต
- เพดานงบประมาณรายเอเจนต์ที่ fail closed

คุณได้รับสิ่งเหล่านี้โดยการสมัคร ไม่ใช่โดยการอ่านคู่มือ harden แล้วลงมือทำเอง สำหรับรันไทม์ที่อยู่ข้างใต้ ดูภาพรวม[AI agent platform](/learn/ai-agent-platform)

## คำถามที่พบบ่อย

### Managed AI agent hosting คืออะไร

Managed AI agent hosting คือบริการที่ provision และดำเนินการโครงสร้างพื้นฐานที่ AI agent อัตโนมัติต้องการ: คอนเทนเนอร์ที่แยก, vault ข้อมูลรับรอง, การบังคับงบประมาณ, เครือข่าย และแดชบอร์ดควบคุม เพื่อให้ทีมดีพลอยและรันฝูงเอเจนต์ได้โดยไม่ต้องสร้างหรือดูแลโครงสร้างพื้นฐานนั้น กับ OpenLegion คุณเข้าสู่ระบบด้วย Google แล้วเริ่มได้เลย — ไม่มีอะไรต้องติดตั้งและไม่ต้องเช่า VPS เฉพาะ

### Managed hosting ต่างจากการ self-host OpenLegion อย่างไร

OpenLegion เป็นเว็บแอปที่โฮสต์ให้ และไม่มีแพลตฟอร์ม self-host ตอนเปิดตัว Self-host โดยทั่วไปหมายถึงคุณรันเซิร์ฟเวอร์, ดำเนินการ vault และใช้การอัปเดตเอง ซึ่งเหมาะกับสภาพแวดล้อมที่ถูกกำกับดูแลหรือ air-gapped Managed hosting หมายถึง OpenLegion รันแพลตฟอร์ม, ดำเนินการ vault และแพตช์ให้คุณ เอนจินที่อยู่ข้างใต้เผยแพร่แบบ source-available ภายใต้ PolyForm Perimeter License 1.0.1

### ปลอดภัยหรือไม่ที่จะโฮสต์ AI agent ที่ถือ API key และคีย์กระเป๋าเงินของฉัน

ปลอดภัย เมื่อคีย์ไม่เคยอยู่ภายในเอเจนต์ บน OpenLegion, API key และ OAuth token ถูกถือไว้ใน vault และถูกฉีดเข้าไปนอกโมเดล ซึ่งถือเพียง handle เท่านั้น ดังนั้นแม้เอเจนต์ที่ถูกบุกรุกเต็มที่ก็อ่านหรือดูด secret ไม่ได้ OpenLegion ไม่ถือคีย์กระเป๋าเงินหรือเงินของเอเจนต์เลย

แพลนฟรีคือ $0 พร้อม 1,000 เครดิตครั้งเดียวโดยไม่ต้องใช้บัตร; Pro คือ $29/เดือนพร้อม 10,000 เครดิต; Team คือ $99/เดือนพร้อม 35,000; Enterprise เริ่มที่ $1,500 ค่าธรรมเนียมครอบคลุมแพลตฟอร์มที่โฮสต์ให้, vault ข้อมูลรับรอง, แดชบอร์ด และเครดิตที่รวมมาในแพลน — ไม่มี VPS เฉพาะให้จ่าย งานถูกคิดเป็นเครดิต เครดิตละ $0.001 เครดิตที่รวมมารีเฟรชรายเดือน และแพ็กเครดิตที่ซื้อไม่มีวันหมดอายุ

### ฉันต้องรู้ Docker หรือ DevOps เพื่อใช้ managed hosting หรือไม่

ไม่ OpenLegion เป็นเว็บแอปที่โฮสต์ให้: เข้าสู่ระบบด้วย Google แล้วเริ่มได้เลย — ไม่มีอะไรต้องติดตั้ง คุณทำงานผ่านแดชบอร์ด: อธิบายทีมที่คุณต้องการ แล้วผู้ช่วยจะสร้างเพื่อนร่วมทีมที่ต้องการ Docker, Python และการดูแลเซิร์ฟเวอร์ไม่ใช่ส่วนหนึ่งของมันเลย

### ฉันย้ายจาก managed hosting ไป self-host ภายหลังได้หรือไม่

ยังไม่ได้ตอนเปิดตัว แพลตฟอร์มที่โฮสต์ให้เป็นวิธีเดียวที่จะรัน OpenLegion ในวันนี้ และมันเป็นกรรมสิทธิ์; เอนจินที่อยู่ข้างใต้เผยแพร่แบบ source-available ภายใต้ PolyForm Perimeter License 1.0.1 ยังไม่มีดิสทริบิวชัน self-host ให้ย้ายไป จึงควรวางแผนใช้แพลตฟอร์มที่โฮสต์ให้ไปก่อน

### ฉันโฮสต์เอเจนต์ได้กี่ตัวบนแผนแบบจัดการให้

ขีดจำกัดเอเจนต์ขยายตามระดับของแผน จากทีมเล็กบนแผนเริ่มต้นไปจนถึงทีมใหญ่บนระดับที่สูงกว่า พร้อมขีดจำกัดแบบกำหนดเองสำหรับองค์กร เอเจนต์เป็นเรคคอร์ดถาวรมากกว่าเซิร์ฟเวอร์ การสร้างจึงเกิดขึ้นทันทีและเอเจนต์ที่ว่างไม่มีค่าใช้จ่าย — เอเจนต์แต่ละตัวนับเป็นหนึ่งต่อขีดจำกัด ดังนั้นทีมสามบทบาทอย่าง Dev Team จึงนับเป็นสามเอเจนต์
